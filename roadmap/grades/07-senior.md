# Roadmap: Senior (top)

[Все грейды](./README.md) · [Общий план](../../README.md) · [Матрица требований](../all-grades.md)

Здесь собраны вопросы по требованиям, которые **впервые появляются на уровне Senior (top)**: 8 технических и 5 поведенческих. Формулировки требований взяты из исходной Excel-матрицы; вопросы, уточнения и практика — учебная программа подготовки.

## Обязательная база

Перед этим roadmap нужно уметь отвечать на вопросы предыдущих уровней: [Intern: база перед Junior](./00-intern-base.md) → [Junior 1](./01-junior-1.md) → [Junior 2](./02-junior-2.md) → [Junior 3](./03-junior-3.md) → [Middle 1](./04-middle-1.md) → [Middle 2](./05-middle-2.md) → [Middle 3](./06-middle-3.md).

## Как проходить вопрос

1. Ответь на основной вопрос за 1–2 минуты своими словами.
2. Ответь на уточнение без чтения материала.
3. Выполни практическую проверку или разбери пример.
4. Поставь `[x]`, только если можешь повторить ответ через несколько дней.

Формула сильного ответа: **определение → механизм → пример → ограничение или риск → вывод**.

## Ответственность уровня

- Стейкхолдинг
- Решает самые сложные баги связанные с системой либо сторонними библиотеками
- Участие в развитии технического бренда
- Настройка и отслеживание технических метрик и ошибок

## Когда roadmap пройден

- Все основные вопросы закрыты без подсказки.

- Есть реальные STAR-примеры для поведенческих вопросов.
- Проведено хотя бы одно пробное интервью по этому уровню.
- Пробелы и дата повторения записаны в [`progress.md`](../progress.md).
