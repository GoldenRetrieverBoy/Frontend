# Roadmap: Intern: база перед Junior

[Все грейды](./README.md) · [Общий план](../../README.md) · [Матрица требований](../all-grades.md)

Здесь собраны вопросы по требованиям, которые **впервые появляются на уровне Intern: база перед Junior**: 14 технических и 9 поведенческих. Формулировки требований взяты из исходной Excel-матрицы; вопросы, уточнения и практика — учебная программа подготовки.

## Как проходить вопрос

1. Ответь на основной вопрос за 1–2 минуты своими словами.
2. Ответь на уточнение без чтения материала.
3. Выполни практическую проверку или разбери пример.
4. Поставь `[x]`, только если можешь повторить ответ через несколько дней.

Формула сильного ответа: **определение → механизм → пример → ограничение или риск → вывод**.

## Ответственность уровня

- Решение простых задач
- Исправление некритичных багов
- Следование принципам разработки ПО, принятым в компании
- Обязательно читать рекомендованную литературу (добавить ссылку)
- Прохождение Code review у разработчиков выше грейдом
