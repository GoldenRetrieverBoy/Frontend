## Как занимаемся

Один вопрос за раз: ты отвечаешь → мы разбираем короткий ответ и пример из файла → решаем новую задачу → записываем результат. Ответ должен объяснять механизм простыми словами. Если база понятна, переходим к ограничениям и рабочим сценариям.

Roadmap определяет порядок и глубину. Каждый вопрос имеет постоянный ID и один разбор в тематическом файле. Ссылка открывает конкретный раздел. Прогресс хранится только в журнале.
