# Поведенческие вопросы

[План](../README.md) · [Прогресс](../roadmap/progress.md)

Сначала ответь на сценарий. Затем приведи собственный пример по схеме: ситуация → задача → твои действия → результат. Учебную ситуацию называй учебной; не выдавай её за рабочий опыт. Числа и результат не выдумывай.

Для каждого сценария сначала предложи последовательность действий, участника согласования и проверяемый результат. Затем открой ориентир. Для подтверждения навыка добавь собственный пример в журнал.
