## Что сделано

### 1. Компактный поиск и SERP editor

**Что было сделано**

- Добавлен компактный поиск на SERP для авиа, ЖД и отелей.
- Введена отдельная state machine для disclosure/overlay: клик по сегменту сразу открывает нужное поле (2 действия → 1).
- Hover-раскрытие убрано; закрытие — click-outside / Escape / submit, без вспышки полной формы.
- Добавлены независимые rollout-флаги для включения по доменам.
- Исправлены сценарии раскрытия/схлопывания, поведение при скролле и prefill из поездки.
- Убраны старые migrated paths после перевода на новый механизм.
- Добавлена cross-domain acceptance matrix для авиа, ЖД и отелей.

**Что улучшилось**

- User flow короче: было два действия (раскрыть форму → выбрать поле), стало одно — клик по сегменту компакт-бара сразу открывает маршрут / даты / гостей.
- Форма открывается оверлеем над выдачей, список не прыгает; закрытие без вспышки полной формы.
- Поведение поиска единое для авиа, ЖД и отелей.
- Снижены race-condition риски при повторном поиске; редактор схлопывается, пока грузятся результаты.

### 3. Авиа booking: тарифы, сервисные сборы и extras

**Что было сделано**

- Исправлено сохранение выбранного fare family при переходе с выдачи на детали бронирования.
- Booking init теперь учитывает `fareFamilyId`, а дальнейшие продукты/seatmap/order creation опираются на актуальный `details.offer.id`.
- Сервисный сбор провайдера показан на booking, payment и order details.
- Добавлен fallback total price от offer price, чтобы не ломать payment totals при неполных данных.
- Исправлены состояния SMS extras: недоступная услуга больше не выглядит как бесплатная `+0 ₸`.
- Улучшены состояния багажа/extras: активная кнопка не выглядит disabled, несколько fare cards могут оставаться раскрытыми.

**Что улучшилось**

- Пользователь бронирует именно выбранный тариф, а не самый дешевый fallback.
- Стоимость поездки стала прозрачнее: отдельно видны сервисные сборы.
- Extras не вводят пользователя в заблуждение: disabled и free состояния разделены.

**Демо-сюжет**

- Git-метрики показывают масштаб инженерных изменений, но не доказывают продуктовый эффект.
