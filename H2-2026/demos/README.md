# Demos — H2 2026

В этой папке хранятся заметки и результаты всех демо второго полугодия 2026.

## Структура

- один каталог на месяц: YYYY-MM;
- один файл на demo/release: X.Y.Z.md;
- сырые заметки добавляются в Inbox конкретного demo;
- после показа в том же файле заполняются feedback, решения и follow-up.

## Процесс

1. Создать файл из [общего шаблона](../../templates/demo-template.md).
2. В течение спринта складывать заметки в Inbox.
3. Перед demo сформировать narrative и run of show.
4. После demo записать фактический показ, реакцию, решения и follow-up.
5. В highlights переносить capability delivery, а measured impact — только после появления метрик.
