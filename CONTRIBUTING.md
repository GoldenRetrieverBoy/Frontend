# Как поддерживать материалы

## Где что хранится

- README — вход и навигация, без копии прогресса.
- roadmap/grades — порядок вопросов и глубина каждого грейда, без ответов и чекбоксов.
- Тематические папки — единственный текст каждого вопроса, ответ, пример и практика.
- roadmap/matrix-coverage.md — исходные требования, первый грейд и соответствие ID.
- roadmap/progress.md — единственное место оценок, подтверждений и следующего шага.
- interviews — сценарии итоговой проверки.

## Изменение вопроса

Сохраняй существующий ID. Новый вопрос получает следующий свободный номер внутри темы и явный HTML-якорь из ID в нижнем регистре. В заголовке сформулируй конкретный вопрос, а не «Объясните требование…». В roadmap добавляй ссылку на якорь; несколько грейдов могут ссылаться на один вопрос с разной глубиной.

Разбор должен содержать короткий ответ, механизм, конкретный пример, практическое условие и критерий результата. Решение новой практики помещай в details, чтобы можно было сначала ответить самостоятельно. Не считать одну строку Excel одним вопросом: перечисленные внутри неё навыки проверяются отдельно.

Версионные и юридические утверждения сверяй по первичным источникам и указывай дату проверки при существенном изменении. Условные темы помечай явно. Не выдавай ссылку на общую документацию за готовый учебный разбор.

## Проверка изменений

Проверь уникальность ID, существование файлов и якорей, соответствие строк матрицы, сохранение старых ссылок и прогресса. Код проверяй в подходящей среде по контракту примера. Не запускай фрагменты с внешними сервисами как готовое приложение. Старые входные файлы можно оставить короткими ссылками, без копии курса.

Из корня репозитория запусти `python3 scripts/check_materials.py`. Проверка не обращается к сети и не требует сторонних пакетов. Она проверяет локальные ссылки и якоря, уникальность ID, наличие всех уроков в журнале и 206 строк исходной матрицы. Техническую корректность ответов и работоспособность внешних сервисов эта проверка не доказывает.
