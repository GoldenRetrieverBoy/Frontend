# Выбери целевой грейд

[Главная](../../README.md) · [Продолжить занятие](../progress.md) · [Матрица](../all-grades.md)

Порядок: диагностика базы → маршрут целевого уровня → возврат к найденным пробелам → пробное интервью. Не обязательно учить всю базу заново.

| Уровень | Новых требований: техника / soft skills | Требуемая глубина |
|---|---:|---|
| [Intern: база перед Junior](00-intern-base.md) | 14 / 9 | Объяснить термин и выполнить небольшой пример с понятным входом и результатом. |
| [Junior 1](01-junior-1.md) | 22 / 9 | Объяснить стандартный случай и самостоятельно выполнить небольшую задачу. |
| [Junior 2](02-junior-2.md) | 21 / 8 | Объяснить механизм, разобрать ошибку и граничный случай. |
| [Junior 3](03-junior-3.md) | 17 / 10 | Связать несколько механизмов и обосновать решение в сценарии приложения. |
| [Middle 1](04-middle-1.md) | 24 / 19 | Самостоятельно выбрать решение с учётом зависимостей, тестов и сопровождения. |
| [Middle 2](05-middle-2.md) | 17 / 8 | Сравнить альтернативы, оценить риски и измерить результат изменения. |
| [Middle 3](06-middle-3.md) | 9 / 6 | Разобрать отказ, восстановление и предотвращение повторения; учитывать работу команды. |
| [Senior (top)](07-senior.md) | 8 / 5 | Оценить системные последствия, границы ответственности и внедрение между командами. |

Число требований не равно числу вопросов: крупная строка может раскрыться несколькими уроками, а один урок — покрывать несколько строк. Все оценки хранятся только в [журнале](../progress.md).
